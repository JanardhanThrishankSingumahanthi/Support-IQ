# SupportIQ — Shared Agent Instructions

## Mission

Build SupportIQ as a professional enterprise support assistant experience based on the supplied UI references and the locked logo.

## Non-negotiable visual rules

- The SupportIQ logo is locked and must remain intact.
- Never redesign, recolor, reinterpret, regenerate, or replace the logo.
- Use the provided screenshots as the primary visual reference.
- Match the tone and structure of the approved design: clean, dark enterprise dashboard, modern support tooling, realistic UI details.
- Avoid robots, mascots, planets, stars, futuristic graphics, or glows.
- Keep visuals polished, credible, and enterprise-grade.

## Development boundaries

- Do not implement application features before the user approves the next division.
- Do not proceed past the current setup division unless explicitly instructed.
- Stay within the currently approved scope.
- Prefer exact adherence to the supplied design language over stylistic invention.

## Repository expectations

- Preserve existing work.
- Do not delete or overwrite user files without clear approval.
- Keep documentation honest and grounded in the actual repo state.
- Use project-level instructions to reinforce the design and workflow constraints for future sessions.
